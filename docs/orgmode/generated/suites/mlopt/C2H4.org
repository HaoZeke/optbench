   <dt>Note</dt><dd>The ranked Optax force rows are the finite-difference fingerprint derivative. The neighbor list is held fixed and the cutoff is the value in fpParas.dat. PyAMFF python loop_FPs at 8037eb98 sorts neighbor indices and leaves the periodic offsets unsorted. On this trajectory that pairing does not change the stored neighbor blocks. calculate_dG2 raises UnboundLocalError on every image, so the python path has no force loss. The archived configs set fp_engine to Fortran. That Fortran derivative was not executed. There is no second force row from the archived script. templates/optax/README.md has the comparison.</dd>
   <dt>Contract</dt><dd>The columns are the keys shared by every archived file.</dd>
   </dl>
