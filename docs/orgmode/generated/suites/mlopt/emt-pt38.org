   <dl class="bench-rule">
   <dt>Cap</dt><dd>10000 epochs</dd>
   <dt>v2</dt><dd>par2-bootstrap</dd>
   <dt>Note</dt><dd>The ranked Optax force rows are the finite-difference fingerprint derivative. The neighbor list is held fixed and the cutoff is the value in fpParas.dat. PyAMFF python loop_FPs at 8037eb98 sorts neighbor indices and leaves the periodic offsets unsorted, then drops a cross derivative whose offset fails noffset.all() == 0. On this trajectory every offset passes that test, so the python force loss and the ranked force loss agree. The archived configs leave fp_engine unset and use the Fortran default. That Fortran derivative was not executed. There is no second force row from the archived script. templates/optax/README.md has the comparison.</dd>
   </dl>
