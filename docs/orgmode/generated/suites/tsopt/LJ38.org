   <h2>LJ38</h2>
   <dl class="bench-rule">
   <dt>Stop</dt><dd>L2 norm of the force at or below 0.001 energy/distance</dd>
   <dt>Cap</dt><dd>10000 force calls</dd>
   <dt>Starts</dt><dd>200</dd>
   <dt>Potential</dt><dd>lennard-jones</dd>
   <dt>v2</dt><dd>par2-bootstrap</dd>
   <dt>Contract</dt><dd>The columns are the keys shared by every archived file.</dd>
   </dl>
   <p>Rows are ranked by cost inside each method family and on one overall table. A run short of the full set, or a run that is not the stock method, stays off the table.</p>
   <p class="bench-gaps">eOn rows are not yet on the harness counter. A run short of the full set, or a run that is not the stock method, stays off the ranked table. Files with no per-start harness record stay off the ranked table.</p>
