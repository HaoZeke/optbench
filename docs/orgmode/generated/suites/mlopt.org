   <h2>C2H4</h2>
   <dl class="bench-rule">
   <dt>Cap</dt><dd>10000 epochs for energies, 30000 when forces are trained</dd>
   <dt>Stop</dt><dd>L2 norm of each parameter-set gradient at or below 0.02 when only energies are trained</dd>
   <dt>Stop</dt><dd>L2 norm of each parameter-set gradient at or below 0.1 when forces are trained</dd>
   <dt>Starts</dt><dd>50</dd>
   <dt>v2</dt><dd>par2-wilson-bootstrap</dd>
   <dt>Note</dt><dd>The ranked Optax force rows are the finite-difference fingerprint derivative. The neighbor list is held fixed and the cutoff is the value in fpParas.dat. PyAMFF python loop_FPs at 8037eb98 sorts neighbor indices and leaves the periodic offsets unsorted. On this trajectory that pairing does not change the stored neighbor blocks. calculate_dG2 raises UnboundLocalError on every image, so the python path has no force loss. The archived configs set fp_engine to Fortran. That Fortran derivative was not executed. There is no separate paper-comparable row. templates/optax/README.md has the comparison.</dd>
   <dt>Contract</dt><dd>Partly stated. The columns are the keys shared by every archived file.</dd>
   </dl>
