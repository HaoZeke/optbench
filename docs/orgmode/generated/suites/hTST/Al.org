   <h2>Al</h2>
   <dl class="bench-rule">
   <dt>Stop</dt><dd>norm of the force at or below 0.001 eV/Angstrom</dd>
   <dt>Starts</dt><dd>639</dd>
   <dt>Potential</dt><dd>eam (eam_al)</dd>
   <dt>v2</dt><dd>par2-bootstrap</dd>
   <dt>v2 cost</dt><dd>one barrier window: sad-fcs summed until every reference barrier has been seen once</dd>
   <dt>Note</dt><dd>A start is one barrier window. The window closes when each reference barrier below 0.4 eV has been matched once from the processtable. The ranked cost counts every force evaluation: dimer images, minimizations, and prefactor calls. The rate sum uses the search row&#x27;s harmonic prefactor when the row carries one, and 1.2e12 otherwise. The stop is the maximum force on any atom. The potential is eam_al.</dd>
   <dt>Contract</dt><dd>The columns are the keys shared by every archived file.</dd>
   </dl>
   <p>Rows are ranked by cost inside each method family and on one overall table. A run short of the full set, or a run that is not the stock method, stays off the table.</p>
   <p class="bench-gaps">A run short of the full set, or a run that is not the stock method, stays off the ranked table.</p>
